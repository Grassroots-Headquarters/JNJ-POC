# SMS code login for every User, no passwords

Every User, Admins included, logs in with a mobile number and a one-time SMS code, and stays logged in on their phone. Email is collected only for billing receipts. Because one User can be an Admin in one Company and a Subcontractor in another (ADR 0003), login has to belong to the person, not the Role. A single passwordless flow also suits site teams who would otherwise forget passwords. We accept the cost of sending SMS messages and our dependence on an SMS provider.
