# Demos

Clickable HTML demos, one per kind of user, for showing JNJ and other builders before the real app exists. They are not the app: everything runs in the browser with example data, nothing is saved or sent, and they are not tested. Each one starts at the SMS login; any 6-digit code works.

Start at [index.html](./index.html), or open a demo directly:

| Demo | What it shows | claude.ai link (private until shared) |
| --- | --- | --- |
| [site-team](./site-team/) | Sign in on site, materials, tagged photos, issues, team chat; three layouts to compare | [Site Team Flow](https://claude.ai/artifact/DUDxngRKEhw5WAkgejYEZC) |
| [admin](./admin/) | Jobs, materials across Jobs with "Ordered by", Client suggestion approvals, Issues, Job completion, team invites, Quiet hours and Urgent | [Admin Demo](https://claude.ai/artifact/FHpfVhgpiMMSRt4UsasHvn) |
| [subcontractor](./subcontractor/) | One login across contractors, choose contractor, sign in, materials, photos, issues; H&S shown as coming later | [Subcontractor Demo](https://claude.ai/artifact/32EuYbZcHcNNJmG8nK74SF) |
| [client-portal](./client-portal/) | Updates, Client chat with the Quiet hours notice, Choices, Extras and Deductions with Client approvals, Reminders, a Complete Job | [Client Portal Demo](https://claude.ai/artifact/F5ov1ZufKVNTXmDVk944qq) |

Once GitHub Pages is on for this repo (Settings → Pages → Deploy from a branch → main, / root), the demos are public at https://grassroots-headquarters.github.io/JNJ-POC/demo/.

The first Site team prototype lives on the `prototype/site-team-flow` branch.
