# Demos

Clickable HTML demos for showing JNJ and other builders before the real app exists. They are not the app: everything runs in the browser, nothing is saved or sent, and they are not tested.

| Demo | What it shows | Live link |
| --- | --- | --- |
| [site-team](./site-team/index.html) | The Site team flow in three layouts (tiles, chat-first, action-first): sign in on site, request materials, add a tagged photo, flag an issue, message the team | [claude.ai artifact](https://claude.ai/artifact/DUDxngRKEhw5WAkgejYEZC) (private until shared) |

To run one locally, open its `index.html` in a browser.

The first prototype version lives on the `prototype/site-team-flow` branch.
